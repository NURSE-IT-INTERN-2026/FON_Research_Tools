# Requirements — FON Research Tool

ระบบจัดการเอกสารเครื่องมือวิจัย คณะพยาบาลศาสตร์ มหาวิทยาลัยเชียงใหม่

---

## ผู้ใช้งาน 2 บทบาท

### 1. นักศึกษา (Student)

- ล็อกอินด้วย CMU Account (OAuth 2.0)
- ระบบดึงข้อมูลส่วนตัวจาก CMU Login อัตโนมัติ (ชื่อ, อีเมล, รหัสนักศึกษา)
- ข้อมูลวิทยานิพนธ์ดึงจาก Thesis API แสดงผลแบบ real-time (ไม่เก็บใน DB)
- อัปโหลดเอกสารเครื่องมือวิจัย (PDF) พร้อมกรอกชื่อเครื่องมือ
- เมื่อ Submit ส่งอีเมลแจ้งเจ้าหน้าที่ (`supapan.ch@cmu.ac.th` cc `ampika.s@cmu.ac.th`)
- ดูสถานะเอกสารตัวเอง (รอตรวจสอบ / อนุมัติแล้ว / ปฏิเสธแล้ว)
- ลบเอกสารของตัวเอง (เฉพาะที่ยังไม่ได้อนุมัติ)
- ปุ่ม Download PDF ใบรับรองเมื่ออนุมัติแล้ว (ชื่อ, รหัส, รายการเครื่องมือ, วันที่)
- รับอีเมลแจ้งเตือนเมื่อเอกสารได้รับการอนุมัติ/ปฏิเสธ

### 2. เจ้าหน้าที่ (Admin)

- ล็อกอินด้วย CMU Account (OAuth 2.0)
- ดู Dashboard: จำนวนนักศึกษาทั้งหมด, เอกสารทั้งหมด, รอตรวจสอบ, อนุมัติแล้ว + กิจกรรมล่าสุด
- ดูรายการเอกสารทั้งหมด พร้อมกรองตามสถานะ + Backend Pagination
  - Card ด้านบน: รอตรวจสอบ (n), อนุมัติแล้ว (n), เครื่องมือทั้งหมด (n)
  - ตารางข้อมูล + Filter สถานะ
- อนุมัติเอกสาร (ทีละฉบับ หรือ "อนุมัติทั้งหมด" เฉพาะ PENDING) → ส่งอีเมลแจ้งนักศึกษา
- ปฏิเสธเอกสารพร้อมระบุเหตุผล → ส่งอีเมลแจ้งนักศึกษา
- ดู/เปิดไฟล์ PDF เพื่อตรวจสอบ
- ลบเอกสารได้ทุกฉบับ
- ค้นหาจาก ชื่อเครื่องมือ, ชื่อนักศึกษา, รหัสนักศึกษา, ชื่อวิทยานิพนธ์
- ดูรายชื่อนักศึกษาทั้งหมดพร้อมจำนวนเอกสาร
- ดูบันทึกกิจกรรม (Activity Log) + Backend Pagination + Date Filter

---

## ข้อมูลที่เก็บ

### ข้อมูลนักศึกษา (Profile) — เก็บใน DB

- ชื่อ-นามสกุล, อีเมล, รหัสนักศึกษา (ดึงจาก CMU Login อัตโนมัติ)

### ข้อมูลวิทยานิพนธ์ — ไม่เก็บ ❌ ดึงจาก Thesis API แสดงผลเฉยๆ

- ภาควิชา, ระดับปริญญา, หลักสูตร
- ชื่อวิทยานิพนธ์ (ไทย/อังกฤษ)

### เอกสารเครื่องมือวิจัย (Document)

- ชื่อเครื่องมือวิจัย + ไฟล์ PDF (นักศึกษากรอก/อัปโหลดเอง)
- สถานะ: รอตรวจสอบ / อนุมัติแล้ว / ปฏิเสธแล้ว
- วันที่ยื่น, วันที่อนุมัติ, ผู้อนุมัติ, หมายเหตุ

---

## สถานะเอกสาร (Status Flow)

```
นักศึกษา Submit → PENDING (รอตรวจสอบ) → ส่งอีเมลแจ้งแอดมิน

แอดมินอนุมัติ   → APPROVED (อนุมัติแล้ว)  → ส่งอีเมลแจ้งนักศึกษา
แอดมินปฏิเสธ    → REJECTED (ปฏิเสธแล้ว)    → ส่งอีเมลแจ้งนักศึกษา
```

---

## ข้อจำกัดการอัปโหลด

- รับเฉพาะไฟล์ PDF
- ขนาดสูงสุด 100 MB ต่อไฟล์
- เก็บไฟล์บนเซิร์ฟเวอร์ เรียกผ่าน API (ป้องกันด้วย auth)

---

## API สำหรับนักศึกษาตรวจสอบสถานะ

- `GET /api/my/documents` — ดูรายการเอกสารของตัวเอง พร้อมสถานะและเวลาที่ได้รับการอนุมัติ

---

## External APIs

| API | URL | วัตถุประสงค์ |
|---|---|---|
| CMU OAuth | `login.microsoftonline.com/{tenant}/oauth2/v2.0/*` | Login |
| CMU Basic Info | `api.cmu.ac.th/mis/cmuaccount/prod/v3/me/basicinfo` | ข้อมูลผู้ใช้ |
| Thesis API | `mis.nurse.cmu.ac.th/thesis/student/GetDataThesis` | ข้อมูลวิทยานิพนธ์ |
| Email API | `mis.nurse.cmu.ac.th/thesis/EmailApi/*` | ส่งอีเมลแจ้งเตือน |
