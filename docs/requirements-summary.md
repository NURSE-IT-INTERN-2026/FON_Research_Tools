# Requirements — FON Research Tool

ระบบจัดการเอกสารเครื่องมือวิจัย คณะพยาบาลศาสตร์ มหาวิทยาลัยเชียงใหม่

---

## ผู้ใช้งาน 2 บทบาท

### 1. นักศึกษา (Student)

- ล็อกอินด้วย CMU Account (OAuth 2.0)
- ระบบดึงข้อมูลส่วนตัวและวิทยานิพนธ์จาก CMU MIS API อัตโนมัติ
- อัปโหลดเอกสารเครื่องมือวิจัย (PDF) พร้อมกรอกชื่อเครื่องมือ
- ดูสถานะเอกสารตัวเอง (รอตรวจสอบ / อนุมัติแล้ว / ปฏิเสธแล้ว)
- ลบเอกสารของตัวเอง (เฉพาะที่ยังไม่ได้อนุมัติ)
- รับอีเมลแจ้งเตือนเมื่อเอกสารได้รับการอนุมัติ/ปฏิเสธ

### 2. เจ้าหน้าที่ (Admin)

- ล็อกอินด้วย CMU Account (OAuth 2.0)
- ดู Dashboard: จำนวนนักศึกษาทั้งหมด, เอกสารทั้งหมด, รอตรวจสอบ, อนุมัติแล้ว + กิจกรรมล่าสุด
- ดูรายการเอกสารทั้งหมด พร้อมกรองตามสถานะ
- อนุมัติเอกสาร (ทีละฉบับ หรือ "อนุมัติทั้งหมด" เฉพาะที่ PENDING) → ส่งอีเมลแจ้งนักศึกษา
- ปฏิเสธเอกสารพร้อมระบุเหตุผล → ส่งอีเมลแจ้งนักศึกษา
- ดู/เปิดไฟล์ PDF ที่นักศึกษาอัปโหลด
- ลบเอกสารได้ทุกฉบับ
- ค้นหานักศึกษาจากรหัส / ชื่อ / ชื่อวิทยานิพนธ์ (ปุ่ม search บน navbar)
- ดูสถานะนักศึกษา (กำลังศึกษา / ลาออก / พ้นสภาพ) ดึงจาก CMU MIS API
- ดูบันทึกกิจกรรม (Activity Log)

---

## ข้อมูลที่เก็บ

### ข้อมูลนักศึกษา (Profile)

- ชื่อ-นามสกุล, อีเมล, รหัสนักศึกษา (ดึงจาก CMU MIS API อัตโนมัติ)
- ภาควิชา, ระดับปริญญา, หลักสูตร
- ชื่อวิทยานิพนธ์ (ไทย/อังกฤษ)
- สถานะนักศึกษา: กำลังศึกษา / ลาออก / พ้นสภาพ (ดึงจาก CMU MIS API)

### เอกสารเครื่องมือวิจัย (Document)

- ข้อมูลทั้งหมดดึงจาก CMU MIS API ยกเว้น 2 ฟิลด์ที่นักศึกษากรอกเอง:
  - **ชื่อเครื่องมือวิจัย** (เช่น "The Positive Discipline Questionnaire")
  - **ไฟล์ PDF** (อัปโหลด)
- สถานะ: รอตรวจสอบ / อนุมัติแล้ว / ปฏิเสธแล้ว
- ข้อมูลผู้อนุมัติ, วันที่สร้าง/แก้ไข, หมายเหตุ (กรณีปฏิเสธ)

---

## สถานะเอกสาร (Status Flow)

```
นักศึกษาอัปโหลด → PENDING (รอตรวจสอบ)

แอดมินอนุมัติ   → APPROVED (อนุมัติแล้ว)  → ส่งอีเมลแจ้งนักศึกษา
แอดมินปฏิเสธ    → REJECTED (ปฏิเสธแล้ว)    → ส่งอีเมลแจ้งนักศึกษา
```

---

## ข้อจำกัดการอัปโหลด

- รับเฉพาะไฟล์ PDF
- ขนาดสูงสุด 100 MB ต่อไฟล์
- เก็บไฟล์บนเซิร์ฟเวอร์

---

## API สำหรับนักศึกษาตรวจสอบสถานะเอกสาร

- `GET /api/my/documents` — ดูรายการเอกสารของตัวเอง พร้อมสถานะและเวลาที่ได้รับการอนุมัติ
