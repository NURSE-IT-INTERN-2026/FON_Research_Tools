## สรุประบบโดยย่อ

**FON Research Tool** เป็นระบบจัดการเอกสารเครื่องมือวิจัยสำหรับคณะพยาบาลศาสตร์ มหาวิทยาลัยเชียงใหม่ โดย:

- **นักศึกษา** สามารถอัปโหลดเอกสารเครื่องมือวิจัย (PDF) ที่เกี่ยวข้องกับวิทยานิพนธ์ของตน
- **เจ้าหน้าที่/อาจารย์** สามารถค้นหาวิทยานิพนธ์, ตรวจสอบ และอนุมัติเอกสารที่นักศึกษาอัปโหลด
- ระบบใช้ **CMU Microsoft Azure AD OAuth 2.0** ในการยืนยันตัวตน
- พัฒนาด้วย **ASP.NET Web Forms 4.5** และ **Bootstrap 4**
