# ผังการทำงานของระบบ (Navigation Flow)

## แผนภาพการไหลของระบบ

```
                          ┌─────────────┐
                          │  Login.aspx │ ← CMU OAuth 2.0
                          └──────┬──────┘
                                 │
                    ┌────────────┴────────────┐
                    │                         │
              ┌─────▼─────┐           ┌───────▼──────┐
              │  StdAcc   │           │  MISEmpAcc   │
              │ (นักศึกษา) │           │ (เจ้าหน้าที่)  │
              └─────┬─────┘           └───────┬──────┘
                    │                         │
              ┌─────▼──────┐          ┌───────▼──────────┐
              │ Student.   │          │  Default.aspx    │
              │ aspx       │          │  (ค้นหาวิทยานิพนธ์)│
              └────────────┘          └───────┬──────────┘
                                              │
                              ┌───────────────┼───────────────┐
                              │               │               │
                     ┌────────▼──────┐ ┌──────▼──────┐ ┌─────▼─────────┐
                     │ ResearchTool  │ │  Student.   │ │ ResearchTool  │
                     │ .aspx         │ │  aspx       │ │ List.aspx     │
                     │ (ดูรายละเอียด) │ │ (เลือกนักศึกษา)│ │ (รายการรออนุมัติ)│
                     └───────────────┘ └─────────────┘ └───────┬───────┘
                                                              │
                                                       ┌──────▼──────┐
                                                       │ Student.    │
                                                       │ aspx        │
                                                       │ (อนุมัติเอกสาร)│
                                                       └─────────────┘
```

---

## รายละเอียดแต่ละหน้า

---

### 1. Login.aspx — หน้าล็อกอิน

| รายการ | รายละเอียด |
|---|---|
| **ผู้ใช้งาน** | ทุกคน |
| **หน้าที่** | เชื่อมต่อ CMU OAuth 2.0 เพื่อยืนยันตัวตน |
| **UI** | ไม่มี UI (เป็นเพียง Redirect Handler) |
| **การทำงาน** | รับ Authorization Code จาก Microsoft → แลกเป็น Token → เรียกข้อมูลผู้ใช้ → ตั้งค่า Session → Redirect |

**อ่านเพิ่มเติม:** [02-authentication.md](02-authentication.md)

---

### 2. Default.aspx — หน้าหลัก (ค้นหาวิทยานิพนธ์)

| รายการ | รายละเอียด |
|---|---|
| **ผู้ใช้งาน** | เจ้าหน้าที่/อาจารย์ (`MISEmpAcc`) |
| **หน้าที่** | ค้นหาข้อมูลวิทยานิพนธ์จากคำค้นหลัก (Keyword) |
| **API ที่ใช้** | `StudentThesisProfile.aspx?strFunction=xSelectThesisByKeyword` |

**UI Elements:**
- `txtKeyword` — ช่องกรอกคำค้นหา
- `btnSearch` — ปุ่มค้นหา (สีเขียว)
- `btnReset` — ปุ่มล้างข้อมูล (สีแดง)
- `gvDocument` — ตารางแสดงผลการค้นหา

**คอลัมน์ในตารางผลลัพธ์:**
| ลำดับ | คอลัมน์ | รายละเอียด |
|---|---|---|
| 1 | ลำดับ | เลขลำดับแถว |
| 2 | ชื่อไทย | ชื่อวิทยานิพนธ์ภาษาไทย (ลิงก์เปิด ResearchTool.aspx) |
| 3 | ชื่ออังกฤษ | ชื่อวิทยานิพนธ์ภาษาอังกฤษ |
| 4 | ชื่อนักศึกษา | ชื่อ-สกุลนักศึกษา |
| 5 | เลือก | ปุ่ม "Select" (เฉพาะ Admin เท่านั้น) |

**การนำทาง:**
- คลิกชื่อวิทยานิพนธ์ → เปิด `ResearchTool.aspx?strID={StuID}` ในแท็บใหม่
- คลิก "Select" → ตั้งค่า `Session["student_id"]` → ไป `Student.aspx`

---

### 3. ResearchTool.aspx — หน้ารายละเอียดวิทยานิพนธ์ (Read-only)

| รายการ | รายละเอียด |
|---|---|
| **ผู้ใช้งาน** | ทุกคน (เปิดในแท็บใหม่) |
| **หน้าที่** | แสดงข้อมูลรายละเอียดวิทยานิพนธ์และเอกสารที่อัปโหลด |
| **พารามิเตอร์** | `?strID={StudentID}` |

**ข้อมูลที่แสดง:**
1. **ข้อมูลนักศึกษา** — รูปภาพ, ชื่อ-สกุล, รหัสนักศึกษา, ระดับปริญญา, หลักสูตร
2. **ข้อมูลวิทยานิพนธ์** — ประเภท (วิทยานิพนธ์/การศึกษาอิสระ), ชื่อไทย/อังกฤษ, บทคัดย่อไทย/อังกฤษ
3. **รายการเอกสาร** — ตารางแสดงเอกสารที่อัปโหลด (ลิงก์เปิดไฟล์ PDF)

---

### 4. ResearchToolList.aspx — หน้ารายการเอกสารรออนุมัติ (Admin)

| รายการ | รายละเอียด |
|---|---|
| **ผู้ใช้งาน** | เจ้าหน้าที่/อาจารย์ (`MISEmpAcc`) เท่านั้น |
| **หน้าที่** | แสดงรายการเอกสารทั้งหมด พร้อมกรองตามสถานะการอนุมัติ |

**UI Elements:**
- `ddlListStatus` — Dropdown กรองสถานะ:
  - **ทั้งหมด** — แสดงเอกสารทุกสถานะ
  - **Pending (0)** — รออนุมัติ (แสดงสีแดง)
  - **Approved (1)** — อนุมัติแล้ว (แสดงสีเขียว)
- `btnSearch` / `btnReset` — ปุ่มค้นหา/ล้างข้อมูล
- `gvDocument` — ตารางรายการเอกสาร

**การนำทาง:**
- คลิก "Select" → ตั้งค่า `Session["student_id"]` → ไป `Student.aspx` (เพื่ออนุมัติ)

---

### 5. Student.aspx — หน้าจัดการเอกสารนักศึกษา

| รายการ | รายละเอียด |
|---|---|
| **ผู้ใช้งาน** | นักศึกษา (`StdAcc`) และเจ้าหน้าที่ (`MISEmpAcc`) |
| **หน้าที่** | จัดการเอกสารเครื่องมือวิจัย — อัปโหลด, ลบ, อนุมัติ |

**ข้อมูลที่แสดง:**
1. **ข้อมูลนักศึกษา** — รูปภาพ, ชื่อ, รหัส, ระดับปริญญา, หลักสูตร, เบอร์โทร, อีเมล
2. **ข้อมูลวิทยานิพนธ์** — ประเภท, ชื่อไทย/อังกฤษ, บทคัดย่อไทย/อังกฤษ
3. **แบบฟอร์มอัปโหลด** — ช่องกรอกชื่อเอกสาร, เลือกไฟล์, ปุ่ม Upload
4. **ตารางเอกสาร** — แสดงเอกสารที่อัปโหลด

**ฟังก์ชันการทำงาน:**

| ฟังก์ชัน | คำอธิบาย | ผู้ใช้งานที่มีสิทธิ์ |
|---|---|---|
| **Upload** | อัปโหลดไฟล์ PDF (สูงสุด 10 ไฟล์ต่อครั้ง, ขนาดสูงสุด 100 MB) | นักศึกษา, เจ้าหน้าที่ |
| **Remove** | ลบเอกสาร (ลบทั้งในฐานข้อมูลและไฟล์จริง) | นักศึกษา (ของตัวเอง), เจ้าหน้าที่ (ทุกไฟล์) |
| **Approve** | อนุมัติเอกสาร (เปลี่ยนสถานะจาก Pending → Approved) | เจ้าหน้าที่ เท่านั้น |

**เงื่อนไขการอัปโหลด:**
- รองรับเฉพาะไฟล์ **PDF** เท่านั้น
- ชื่อไฟล์จะถูกสร้างอัตโนมัติเป็น `{StudentID}_{ลำดับ}.pdf`
- ไฟล์ถูกบันทึกที่ `upload/{StudentID}/`
