# คู่มือการใช้งานสำหรับผู้ใช้งาน (User Guide)

---

## สำหรับนักศึกษา (Student)

### ขั้นตอนที่ 1: เข้าสู่ระบบ
1. เปิดเว็บไซต์ `https://mis.nurse.cmu.ac.th/researchTool/`
2. คลิกปุ่ม **Login** ที่แถบนำทางด้านบน
3. ระบบจะเปลี่ยนเส้นทางไปยังหน้าล็อกอินของ **CMU Microsoft**
4. กรอก CMU IT Account และรหัสผ่าน
5. หลังล็อกอินสำเร็จ ระบบจะพาไปยังหน้า **Student.aspx** อัตโนมัติ

### ขั้นตอนที่ 2: ดูข้อมูลส่วนตัวและวิทยานิพนธ์
- หน้า Student.aspx จะแสดง:
  - รูปประจำตัว, ชื่อ-สกุล, รหัสนักศึกษา
  - ระดับปริญญา, หลักสูตร
  - ข้อมูลวิทยานิพนธ์ (ชื่อ, บทคัดย่อ)
  - รายการเอกสารที่เคยอัปโหลด

### ขั้นตอนที่ 3: อัปโหลดเอกสารเครื่องมือวิจัย
1. ในส่วน **"Research Tool"** ด้านล่างของหน้า
2. กรอก **ชื่อเอกสาร** ในช่อง `txtTitle`
3. คลิก **Choose File** เพื่อเลือกไฟล์ PDF
4. คลิกปุ่ม **Upload** (สีเขียว)
5. ระบบจะบันทึกไฟล์และแสดงในตารางด้านล่าง

> **หมายเหตุ:**
> - รองรับเฉพาะไฟล์ **PDF** เท่านั้น
> - อัปโหลดได้สูงสุด **10 ไฟล์** ต่อครั้ง
> - ขนาดไฟล์สูงสุด **100 MB** ต่อไฟล์

### ขั้นตอนที่ 4: ลบเอกสาร
1. ในตารางรายการเอกสาร ให้คลิกปุ่ม **Remove**
2. ระบบจะแสดงกล่องข้อความยืนยัน (Confirmation)
3. คลิก **ตกลง** เพื่อลบ

> **คำเตือน:** การลบจะเป็นการลบถาวรทั้งในระบบและไฟล์จริง

### ขั้นตอนที่ 5: ตรวจสอบสถานะการอนุมัติ
- ในตารางรายการเอกสาร ให้สังเกตสถานะ:
  - **Pending** (สีแดง) = รอการอนุมัติ
  - **Approved** (สีเขียว) = อนุมัติแล้ว

### ขั้นตอนที่ 6: ออกจากระบบ
- คลิก **Logout** ที่เมนูนักศึกษาด้านบน

## สำหรับเจ้าหน้าที่/อาจารย์ (Admin)

### ขั้นตอนที่ 1: เข้าสู่ระบบ
1. เปิดเว็บไซต์ `https://mis.nurse.cmu.ac.th/researchTool/`
2. คลิกปุ่ม **Login** ที่แถบนำทางด้านบน
3. ล็อกอินด้วย CMU IT Account
4. หลังล็อกอินสำเร็จ ระบบจะพาไปยังหน้า **Default.aspx** (หน้าค้นหา)

### ขั้นตอนที่ 2: ค้นหาวิทยานิพนธ์
1. ในหน้า Default.aspx
2. พิมพ์ **Keyword** ที่ต้องการค้นหาในช่องค้นหา
3. คลิกปุ่ม **Search** (สีเขียว)
4. ผลลัพธ์จะแสดงในตารางด้านล่าง

**สิ่งที่สามารถทำได้จากตารางผลลัพธ์:**
- คลิก **ชื่อวิทยานิพนธ์ภาษาไทย** → เปิดหน้ารายละเอียด (ResearchTool.aspx) ในแท็บใหม่
- คลิก **Select** → เปิดหน้าจัดการเอกสารของนักศึกษาคนนั้น

### ขั้นตอนที่ 3: ดูรายการเอกสารรออนุมัติ
1. คลิกเมนู **Research Tool Approvement** ที่แถบนำทาง (Admin Panel)
2. หน้า ResearchToolList.aspx จะแสดงรายการเอกสารทั้งหมด
3. ใช้ Dropdown **สถานะ** เพื่อกรอง:
   - **Select All** — แสดงทั้งหมด
   - **Pending** — เฉพาะที่รออนุมัติ
   - **Approved** — เฉพาะที่อนุมัติแล้ว
4. คลิก **Search** เพื่อกรองข้อมูล

### ขั้นตอนที่ 4: อนุมัติเอกสาร
1. จากหน้า ResearchToolList.aspx คลิก **Select** ที่เอกสารที่ต้องการ
2. ระบบจะพาไปยังหน้า Student.aspx ของนักศึกษาคนนั้น
3. ในตารางเอกสาร คลิกปุ่ม **Approve**
4. สถานะจะเปลี่ยนเป็น "Approved" (สีเขียว) และปุ่มจะถูกปิดใช้งาน

### ขั้นตอนที่ 5: ลบเอกสาร
- เจ้าหน้าที่สามารถลบเอกสารของนักศึกษาคนใดก็ได้ โดยคลิกปุ่ม **Remove**

### ขั้นตอนที่ 6: ดูคู่มือการใช้งาน
- คลิกเมนู **Manual** ที่แถบนำทาง เพื่อเปิดคู่มือ PDF

### ขั้นตอนที่ 7: ออกจากระบบ
- คลิก **Logout** ที่เมนู Admin ด้านบน
