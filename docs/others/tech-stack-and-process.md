### ฟีเจอร์ที่ทำแล้ว (Phase 1)

**1. ระบบล็อกอินด้วย CMU Account**
ล็อกอินผ่าน Microsoft Azure AD → ระบบดึงข้อมูลส่วนตัวอัตโนมัติ (ชื่อ, อีเมล, รหัสนักศึกษา) → แยกบทบาทอัตโนมัติ (นักศึกษา / เจ้าหน้าที่) → นำไปยังหน้าที่ถูกต้อง

**2. หน้านักศึกษา — ข้อมูลส่วนตัวและวิทยานิพนธ์**
แสดงข้อมูลส่วนตัว (ชื่อ-นามสกุล, รหัสนักศึกษา, อีเมล) และข้อมูลวิทยานิพนธ์ (title_th, title_en, curriculum, major_th, level_name_th, cmu_account) ที่ดึงจาก Thesis API

**3. อัปโหลดเอกสารเครื่องมือวิจัย (PDF)**
นักศึกษากรอกชื่อเครื่องมือ + อัปโหลดไฟล์ PDF (รองรับหลายไฟล์พร้อมกัน) → สถานะเปลี่ยนเป็น "รอตรวจสอบ" → ส่ง EMAIL แจ้งเตือนให้เจ้าหน้าที่ email to: supapan.ch@cmu.ac.th cc: ampika.s@cmu.ac.th

**4. ดูสถานะเอกสาร**
นักศึกษาดูสถานะเอกสารตัวเอง: รอตรวจสอบ, อนุมัติแล้ว, ปฏิเสธ พร้อมแสดง วันที่ยื่น, วันที่อนุมัติ, ผู้อนุมัติ

**5. ลบเอกสาร**
นักศึกษาลบเอกสารของตัวเองได้ (เฉพาะที่ยังไม่ได้อนุมัติ)

**6. ดาวน์โหลด PDF ใบรับรอง**
เมื่อได้รับอนุมัติจาก ADMIN แล้ว นักศึกษากดปุ่ม DOWNLOAD PDF แสดงรายละเอียด:
- ชื่อระบบ "Research Tool" Faculty of Nursing, Chiang Mai University
- ชื่อนักศึกษา, รหัส
- รายการเครื่องมือ ......
- ได้บันทึกข้อมูลเครื่องมือวิจัยแล้วเมื่อวันที่.....

**7. หน้าเจ้าหน้าที่ — Dashboard**
แสดงจำนวนนักศึกษาทั้งหมด, เอกสารทั้งหมด, รอตรวจสอบ, อนุมัติแล้ว + กิจกรรมล่าสุด

**8. รายการเอกสารทั้งหมด**
เจ้าหน้าที่ดูรายการเอกสารทั้งหมด พร้อมกรองตามสถานะ:
- มี Card ด้านบน รอตรวจสอบ (5), อนุมัติแล้ว (10), เครื่องมือทั้งหมด (20)
- แสดงตารางข้อมูล (Backend Pagination)
- Filter: สถานะ (ทั้งหมด / รอตรวจสอบ / อนุมัติแล้ว / ปฏิเสธแล้ว)

**9. อนุมัติเอกสาร**
อนุมัติเอกสาร → สถานะเปลี่ยนเป็น "อนุมัติแล้ว" + ส่งอีเมลแจ้งนักศึกษา (อนุมัติทีละรายการ หรือ อนุมัติทั้งหมด)

**10. ปฏิเสธเอกสาร**
ปฏิเสธเอกสารพร้อมระบุเหตุผล → สถานะเปลี่ยนเป็น "ปฏิเสธแล้ว" + ส่งอีเมลแจ้งนักศึกษา

**11. ดู/เปิดไฟล์ PDF**
เจ้าหน้าที่ดู/เปิดไฟล์ PDF เพื่อตรวจสอบความถูกต้องของเครื่องมือที่นักศึกษาอัปโหลด

**12. ลบเอกสาร**
เจ้าหน้าที่ลบเอกสารได้ทุกสถานะ

**13. รายชื่อนักศึกษา**
เจ้าหน้าที่ดูรายชื่อนักศึกษาทั้งหมดพร้อมจำนวนเอกสาร + ดูรายละเอียดนักศึกษาแต่ละคน

**14. ค้นหา**
เจ้าหน้าที่ค้นหานักศึกษาตาม ชื่อเครื่องมือ, ชื่อนักศึกษา, รหัสนักศึกษา, ชื่อวิทยานิพนธ์ (search button on navbar)

**15. บันทึกกิจกรรม (Activity Log)**
เจ้าหน้าที่ดูบันทึกกิจกรรมทั้งหมด พร้อม Backend Pagination และ Date Filter เช่น อยากดู log ของวันที่ 19/5/2026

**16. ส่งอีเมลแจ้งเตือน**
ส่งอีเมลแจ้งเตือนผ่าน CMU Email API:
- เมื่อนักศึกษาอัปโหลดเอกสาร → แจ้งเจ้าหน้าที่
- เมื่อเจ้าหน้าที่อนุมัติ/ปฏิเสธ → แจ้งนักศึกษา

**17. การเก็บไฟล์**
เก็บไว้ใน Project Folder เช่น /upload ใช้การเรียกไฟล์ผ่าน API ป้องกันให้เข้าถึงได้เฉพาะผู้ที่ Login เท่านั้น

---

### ข้อมูลที่เก็บในระบบ

- ชื่อ-นามสกุล, อีเมล, รหัสนักศึกษา: ได้จาก CMU ENTRA LOGIN (SCOPE) อัตโนมัติ
- ชื่อเครื่องมือวิจัย, ชื่อไฟล์, วันที่ยื่น, วันที่ได้รับอนุมัติ

### ข้อมูลวิทยานิพนธ์

- ไม่เก็บในฐานข้อมูล — ดึงจาก Thesis API ทุกครั้งที่แสดงผล
- ยกเว้นชื่อวิทยานิพนธ์ (ไทย/อังกฤษ) ที่เก็บ cache ไว้สำหรับค้นหาเท่านั้น (อัปเดตอัตโนมัติทุกครั้งที่นักศึกษาล็อกอิน)
