# Typhoon OCR — ระบบอ่านเอกสารอัตโนมัติ

## สรุปสั้น ๆ

เมื่อนักศึกษาอัปโหลดใบอนุญาต (PDF) ระบบจะ **อ่านข้อมูลจากเอกสารอัตโนมัติ** แล้วกรอกให้ในฟอร์มแทน เช่น ชื่อผู้ขอ, วันที่, จุดประสงค์การยืม

---

## มันทำงานยังไง

```
นักศึกษาอัปโหลด PDF
        │
        ▼
① ดึงข้อความจาก PDF (pdftotext)
        │
        ├─ เจอข้อมูลครบ? → ส่งผลลัพธ์เลย ✅
        │
        └─ ข้อมูลไม่ครบ? → ส่งรูปให้ Typhoon AI อ่าน 🔍
                │
                └─ เอาผลจากทั้ง 2 วิธีมารวมกัน → ส่งผลลัพธ์ ✅
```

### วิธีที่ 1 — ดึงข้อความจาก PDF (เร็ว, ฟรี)

ระบบใช้โปรแกรม `pdftotext` แปลง PDF เป็นข้อความธรรมดา แล้วหาข้อมูลด้วย pattern เช่น:

| หาอะไร | ตัวอย่างในเอกสาร |
|---|---|
| ชื่อผู้ขอ | `ชื่อผู้ขอ: นางสาวสมหญิง ใจดี` |
| วันที่ | `วันที่ขอ: 15 พฤษภาคม 2569` |
| จุดประสงค์ | `จุดประสงค์การยืม: ใช้เก็บข้อมูลวิจัย...` |

วิธีนี้ทำงานเร็วมาก (วินาทีเดียว) แต่จะใช้ได้กับ PDF ที่เป็น **ข้อความ** (ไม่ใช่รูปสแกน)

### วิธีที่ 2 — Typhoon AI อ่านรูป (ช้ากว่า, แม่นกว่า)

ถ้าวิธีแรกดึงข้อมูลไม่ครบ ระบบจะ:

1. แปลงหน้าแรกของ PDF เป็นรูป PNG
2. ส่งรูปให้ Typhoon Vision AI วิเคราะห์
3. AI อ่านข้อมูลจากรูปแล้วตอบเป็น JSON

วิธีนี้ใช้ได้กับทุกประเภท PDF รวดเร็วต่อการสแกน หรือรูปภาพ

### การรวมผลลัพธ์

ระบบเอาผลจากทั้ง 2 วิธีมารวมกัน — ถ้าวิธีไหนเจอข้อมูลก็ใช้ข้อมูลนั้น:

```
วิธี 1: ชื่อ ✓   วันที่ ✗   จุดประสงค์ ✓
วิธี 2: ชื่อ ✗   วันที่ ✓   จุดประสงค์ ✗
─────────────────────────────────────────────
ผลลัพธ์: ชื่อ ✓   วันที่ ✓   จุดประสงค์ ✓
```

---

## ข้อมูลที่ดึงได้

| ฟิลด์ | ตัวอย่างผลลัพธ์ | หมายเหตุ |
|---|---|---|
| `requesterName` | `นางสาวสมหญิง ใจดี` | ชื่อ-นามสกุลผู้ขอเท่านั้น |
| `requestDate` | `2026-05-15` | แปลง พ.ศ. เป็น ค.ศ. ให้อัตโนมัติ |
| `additionalDetails` | `ใช้เป็นเครื่องมือเก็บข้อมูล...` | จุดประสงค์การยืม |

---

## การแปลงวันที่

ระบบจัดการวันที่ภาษาไทยได้หลายรูปแบบ:

| รูปแบบในเอกสาร | ผลลัพธ์ |
|---|---|
| `15 พฤษภาคม 2569` | `2026-05-15` |
| `15 พ.ค. 2569` | `2026-05-15` |
| `15-05-2569` | `2026-05-15` |
| `2569-05-15` | `2026-05-15` |
| `๑๕ พฤษภาคม ๒๕๖๙` (ตัวเลขไทย) | `2026-05-15` |

## ตั้งค่า Environment Variables

เพิ่มใน `.env.local`:

```env
# Typhoon OCR (ไม่ตั้งค่าก็ใช้ได้ แต่จะอ่านได้แค่ข้อความจาก PDF เท่านั้น)
TYPHOON_BASE_URL=https://api.opentyphoon.ai
TYPHOON_API_KEY=your-api-key-here
TYPHOON_OCR_MODEL=typhoon-ocr
```

| ตัวแปร | ต้องมีไหม | ค่าเริ่มต้น | คืออะไร |
|---|---|---|---|
| `TYPHOON_BASE_URL` | ไม่ต้อง | - | URL ของ Typhoon API |
| `TYPHOON_API_KEY` | ไม่ต้อง | - | API key สำหรับเรียก Typhoon |
| `TYPHOON_OCR_MODEL` | ไม่ต้อง | `typhoon-ocr` | ชื่อโมเดลที่ใช้ |

**ถ้าไม่ตั้งค่า** ระบบจะใช้แค่วิธีที่ 1 (ดึงข้อความจาก PDF) ซึ่งใช้ได้กับ PDF ที่เป็นข้อความเท่านั้น

## โปรแกรมที่ต้องติดตั้งบนเซิร์ฟเวอร์

| โปรแกรม | ติดตั้งยังไง | ใช้ทำอะไร |
|---|---|---|
| `pdftotext` | `apt install poppler-utils` | ดึงข้อความจาก PDF |
| `pdftoppm` | มาพร้อม poppler-utils | แปลง PDF เป็นรูป (Linux) |
| `sips` | มาพร้อม macOS | แปลง PDF เป็นรูป (macOS) |

---

## ไฟล์ที่เกี่ยวข้อง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/lib/ocr.ts` | ตัวหลัก — ดึงข้อความ, เรียก Typhoon API, แปลงวันที่ภาษาไทย |
| `src/lib/pdf-to-image.ts` | แปลง PDF เป็นรูป PNG (ใช้ sips หรือ pdftoppm) |
| `src/actions/ocr-actions.ts` | Server Action — ตรวจสอบสิทธิ์ + ตรวจไฟล์ + เรียก OCR |
| `.agents/skills/typhoon-ocr/SKILL.md` | Skill สำหรับ AI agent อ่านเวลาจะแก้ไข OCR |

## ข้อจำกัด

- รองรับเฉพาะ **PDF** (ไม่รองรับรูปภาพโดยตรง)
- ขนาดไฟล์สูงสุด **10 MB**
- Typhoon API อ่านเฉพาะ **หน้าแรก** ของ PDF
- ถ้าเอกสารไม่มีโครงสร้างชัดเจน ข้อมูลอาจไม่ครบ
- นักศึกษาต้องกดปุ่ม "อ่านเอกสารอัตโนมัติ" เอง (ไม่ได้อ่านอัตโนมัติตอนอัปโหลด)
- หลังจากอ่านเสร็จ นักศึกษาสามารถแก้ไขข้อมูลได้ก่อนส่งคำขอ
