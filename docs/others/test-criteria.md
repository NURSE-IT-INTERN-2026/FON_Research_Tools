# Test Criteria — FON Research Tool

## โปรเจคเกี่ยวกับอะไร

ระบบจัดการเอกสารเครื่องมือวิจัย ของคณะพยาบาลศาสตร์ มหาวิทยาลัยเชียงใหม่

- **นักศึกษา** ล็อกอินด้วย CMU Account → อัปโหลดเอกสารเครื่องมือวิจัย (PDF) → ยื่นขอยืมเครื่องมือวิจัย → ดูสถานะเอกสาร/การยืมของตัวเอง
- **เจ้าหน้าที่** ล็อกอินด้วย CMU Account หรือ username/password → อนุมัติ/ปฏิเสธเอกสาร → อนุมัติ/ปฏิเสธคำขอยืม → ดู Dashboard/รายงาน

**URL:** `http://localhost:4141/researchtool`
**Tech:** Next.js 16, React 19, Tailwind CSS v4, shadcn/ui, Prisma 7, PostgreSQL

## Flow ที่ต้องทดสอบ

### Flow 1: เอกสารเครื่องมือวิจัย (Document)

```
นักศึกษาอัปโหลด → Admin อนุมัติ/ปฏิเสธ → นักศึกษาเห็นผล
```

#### 1.1 นักศึกษาอัปโหลดเอกสาร

- [ ] เข้า `/thesis` (ต้องล็อกอินก่อน ถ้าไม่ได้ล็อกอิน redirect ไป `/login`)
- [ ] เห็นข้อมูลส่วนตัว (ชื่อ, รหัสนักศึกษา, อีเมล)
- [ ] เห็นข้อมูลวิทยานิพนธ์ (ชื่อไทย/อังกฤษ, สาขา, หลักสูตร)
- [ ] กรอกชื่อเครื่องมือวิจัย + เลือกไฟล์ PDF → กดอัปโหลด
- [ ] เห็น dialog ยืนยัน → กดยืนยัน
- [ ] Toast "อัปโหลดเอกสารสำเร็จ"
- [ ] เอกสารใหม่ปรากฏในรายการ สถานะ "รอตรวจสอบ" (สีเหลือง)
- [ ] เพิ่มได้หลายไฟล์พร้อมกัน (กด "เพิ่มเอกสาร")
- [ ] ไฟล์ต้องเป็น PDF เท่านั้น, ขนาดไม่เกิน 10 MB

#### 1.2 เจ้าหน้าที่อนุมัติเอกสาร

- [ ] เข้า `/admin/documents`
- [ ] เห็น Status Cards (ทั้งหมด, รอตรวจสอบ, อนุมัติแล้ว, ปฏิเสธแล้ว) พร้อมจำนวน
- [ ] เห็นตารางเอกสาร มีคอลัมน์: ลำดับ, ชื่อนักศึกษา, รหัสนักศึกษา, ชื่อเครื่องมือ, ไฟล์, สถานะ, วันที่ดำเนินการ, วันที่อัปโหลด, ผู้ดำเนินการ, ดำเนินการ
- [ ] กดปุ่ม ✓ (อนุมัติ) ที่เอกสารสถานะ "รอตรวจสอบ"
- [ ] เห็น dialog ยืนยัน → กดอนุมัติ
- [ ] Toast "อนุมัติเอกสารสำเร็จ"
- [ ] สถานะเอกสารเปลี่ยนเป็น "อนุมัติแล้ว" (สีเขียว)
- [ ] วันที่ดำเนินการ + ผู้ดำเนินการ แสดงข้อมูลแล้ว
- [ ] Filter "อนุมัติแล้ว" เรียงตามวันที่ดำเนินการล่าสุดก่อน

#### 1.3 เจ้าหน้าที่ปฏิเสธเอกสาร

- [ ] กดปุ่ม ✕ (ปฏิเสธ) ที่เอกสารสถานะ "รอตรวจสอบ"
- [ ] เห็น dialog ให้กรอกเหตุผล
- [ ] กรอกเหตุผล → กดปฏิเสธ
- [ ] Toast "ปฏิเสธเอกสารสำเร็จ"
- [ ] สถานะเปลี่ยนเป็น "ปฏิเสธแล้ว" (สีแดง)
- [ ] มีเหตุผลแสดงในคอลัมน์ดำเนินการ
- [ ] Filter "ปฏิเสธแล้ว" เรียงตามวันที่ดำเนินการล่าสุดก่อน

#### 1.4 นักศึกษาเห็นผล

- [ ] เข้า `/thesis`
- [ ] เอกสารที่อนุมัติ: สถานะ "อนุมัติแล้ว", มีวันที่อนุมัติ + ผู้อนุมัติ, มีปุ่ม "ใบรับรอง" (ดาวน์โหลด PDF)
- [ ] เอกสารที่ปฏิเสธ: สถานะ "ปฏิเสธแล้ว", มีเหตุผล, มีปุ่ม "ลบ"
- [ ] เอกสารที่ปฏิเสธ ลบได้

#### 1.5 อนุมัติทั้งหมด (Bulk Approve)

- [ ] ที่หน้า student detail `/admin/students/[id]` หรือ documents page
- [ ] กดปุ่ม "อนุมัติทั้งหมด" (แสดงเฉพาะเมื่อมี PENDING > 1)
- [ ] เอกสาร PENDING ทั้งหมดของนักศึกษาคนนั้นเปลี่ยนเป็น APPROVED

### Flow 2: ยืมเครื่องมือวิจัย (Borrowing)

```
นักศึกษายื่นขอยืม → Admin อนุมัติ/ปฏิเสธ → นักศึกษาเห็นผล
```

#### 2.1 นักศึกษายื่นขอยืม

- [ ] เข้า `/borrow`
- [ ] เห็นรายการเครื่องมือวิจัยที่มีในระบบ
- [ ] เลือกเครื่องมือ + กรอกชื่อผู้ขอ + วันที่ขอ + อัปโหลดใบอนุญาต PDF
- [ ] ส่งคำขอ → Toast สำเร็จ
- [ ] คำขอปรากฏในรายการ สถานะ "รอตรวจสอบ"

#### 2.2 เจ้าหน้าที่อนุมัติคำขอยืม

- [ ] เข้า `/admin/borrowing`
- [ ] เห็น Status Cards เหมือนหน้าเอกสาร (ทั้งหมด, รอตรวจสอบ, อนุมัติแล้ว, ปฏิเสธแล้ว)
- [ ] มี Search bar ค้นหาได้
- [ ] ตารางมีคอลัมน์: ลำดับ, นักศึกษา, เครื่องมือวิจัย, ใบอนุญาต, สถานะ, วันที่ดำเนินการ, วันที่ยื่น, ผู้ดำเนินการ, ดำเนินการ
- [ ] กด ✓ (อนุมัติ) → สถานะเปลี่ยนเป็น "อนุมัติแล้ว"
- [ ] วันที่ดำเนินการ + ผู้ดำเนินการ แสดงข้อมูล

#### 2.3 เจ้าหน้าที่ปฏิเสธคำขอยืม

- [ ] กด ✕ (ปฏิเสธ) → กรอกเหตุผล → ปฏิเสธ
- [ ] สถานะเปลี่ยนเป็น "ปฏิเสธแล้ว"
- [ ] เหตุผลแสดงในตาราง

#### 2.4 นักศึกษาเห็นผล

- [ ] เข้า `/borrow`
- [ ] เห็นสถานะคำขอยืมทั้งหมด (APPROVED/REJECTED/PENDING)
- [ ] คำขอที่ปฏิเสธมีเหตุผลแสดง

### Flow 3: RBAC (Role-Based Access Control)

#### 3.1 การเข้าถึงหน้า

- [ ] ไม่ล็อกอิน → เข้า `/thesis`, `/borrow`, `/admin/*` → redirect ไป `/login` หรือ 401
- [ ] ล็อกอิน student → เข้า `/admin/*` → 403 Forbidden
- [ ] ล็อกอิน admin → เข้า `/thesis`, `/borrow` → 403 Forbidden
- [ ] หน้า public (`/`, `/login`, `/admin/login`) → เข้าได้โดยไม่ต้องล็อกอิน
- [ ] ล็อกอินแล้วเข้า `/login` → redirect ไป dashboard ตาม role

#### 3.2 สี Theme

- [ ] Student pages → sidebar สีส้ม (orange)
- [ ] Admin pages → sidebar สีม่วง (purple)

---

### Flow 4: หน้าเจ้าหน้าที่ (Admin Pages)

#### 4.1 Dashboard (`/admin/dashboard`)

- [ ] เห็น Stat Cards (เอกสารทั้งหมด, รอตรวจสอบ, อนุมัติแล้ว, ปฏิเสธแล้ว)
- [ ] เห็น Activity Log ล่าสุด

#### 4.2 Documents (`/admin/documents`)

- [ ] Status Cards คลิกได้ → filter ตามสถานะ
- [ ] Search bar ค้นหาจากชื่อเครื่องมือ, ชื่อนักศึกษา, รหัสนักศึกษา
- [ ] Pagination (10/หน้า)
- [ ] นักศึกษาที่มีหลายไฟล์ → แสดง "มีอีก N ไฟล์" กดขยายได้
- [ ] คลิกชื่อนักศึกษา → ไปหน้า student detail

#### 4.3 Students (`/admin/students`)

- [ ] รายชื่อนักศึกษาทั้งหมด
- [ ] แสดงจำนวนเอกสารต่อคน
- [ ] คลิกชื่อ → หน้า student detail

#### 4.4 Student Detail (`/admin/students/[id]`)

- [ ] ข้อมูลส่วนตัว + วิทยานิพนธ์
- [ ] รายการเอกสาร + อนุมัติ/ปฏิเสธ/ลบ ได้
- [ ] ปุ่ม "อนุมัติทั้งหมด"

#### 4.5 Borrowing (`/admin/borrowing`)

- [ ] UI เหมือนหน้า Documents (Status Cards, Search, Pagination)
- [ ] Filter ตามสถานะได้
- [ ] ค้นหาได้

#### 4.6 Activity Log (`/admin/activity-log`)

- [ ] แสดง log ทั้งหมด
- [ ] Filter + search ได้

---

### Flow 5: การลบ (Remove)

- [ ] นักศึกษาลบเอกสาร PENDING ของตัวเองได้
- [ ] นักศึกษาลบเอกสาร REJECTED ของตัวเองได้
- [ ] นักศึกษาลบเอกสาร APPROVED ไม่ได้
- [ ] Admin ลบเอกสารได้ทุกสถานะ
- [ ] ก่อนลบมี dialog ยืนยัน

---

### Flow 6: ข้อความภาษาไทย

- [ ] ทุกหน้า ข้อความทั้งหมดเป็นภาษาไทย (heading, label, button, placeholder, toast, empty state)
- [ ] Status badge: รอตรวจสอบ, อนุมัติแล้ว, ปฏิเสธแล้ว
- [ ] Role: เจ้าหน้าที่, นักศึกษา

---

### Flow 7: Responsive

- [ ] Desktop: ตารางแสดงปกติ
- [ ] Mobile: สลับเป็น card layout
- [ ] Sidebar: desktop แสดงตลอด, mobile มี hamburger toggle

---

### Flow 8: Logout

- [ ] กด "ออกจากระบบ" ใน sidebar → session ถูกลบ → redirect ไปหน้า landing
