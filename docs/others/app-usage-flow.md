# ขั้นตอนการใช้งานแอปพลิเคชัน

เอกสารฉบับนี้สรุปขั้นตอนการใช้งานระบบจัดการเอกสารเครื่องมือวิจัย แบ่งตามบทบาทผู้ใช้งาน

---

## นักศึกษา (Student)

```
 ┌─────────────────────────────────────────────────────────────────┐
 │                    ขั้นตอนการใช้งานสำหรับนักศึกษา                   │
 └─────────────────────────────────────────────────────────────────┘

 ① เข้าสู่ระบบ
 ────────────────────────────────────────────────────────────────
   เปิดเว็บไซต์ → กดปุ่ม "เข้าสู่ระบบ"
   → ล็อกอินด้วย CMU Account (Microsoft)
   → เข้าสู่หน้า Dashboard อัตโนมัติ

 ② ดูข้อมูลส่วนตัวและวิทยานิพนธ์
 ────────────────────────────────────────────────────────────────
   หน้า Dashboard แสดง:
   - ชื่อ-นามสกุล, อีเมล, รหัสนักศึกษา
   - ชื่อวิทยานิพนธ์ (ไทย/อังกฤษ), ภาควิชา, หลักสูตร
   - รายการเอกสารเครื่องมือวิจัยที่เคยอัปโหลด

 ③ อัปโหลดเอกสารเครื่องมือวิจัย
 ────────────────────────────────────────────────────────────────
   กรอกชื่อเครื่องมือวิจัย + เลือกไฟล์ PDF
   → ยืนยันการอัปโหลด
   → ระบบส่งอีเมลแจ้งเตือนเจ้าหน้าที่อัตโนมัติ
   → เอกสารมีสถานะ "รอตรวจสอบ"

   📎 รองรับหลายฉบับพร้อมกัน
   📎 ไฟล์ PDF เท่านั้น, ไม่เกิน 10 MB ต่อฉบับ

 ④ ติดตามสถานะเอกสาร
 ────────────────────────────────────────────────────────────────
   ดูได้ที่หน้า Dashboard:

   ┌────────────────┐   ┌────────────────┐   ┌────────────────┐
   │  รอตรวจสอบ      │   │  อนุมัติแล้ว       │   │  ปฏิเสธแล้ว      │
   │  (ส้ม)          │   │  (เขียว)         │   │  (แดง)         │
   │                │   │                │   │                │
   │  รอเจ้าหน้าที่    │   │  ดาวน์โหลด      │   │  ดูเหตุผล       │
   │  ตรวจสอบ       │   │  ใบรับรองได้     │   │  → อัปโหลดใหม่  │
   └────────────────┘   └────────────────┘   └────────────────┘

 ⑤ ดาวน์โหลดใบรับรอง (เมื่ออนุมัติแล้ว)
 ────────────────────────────────────────────────────────────────
   เอกสารที่อนุมัติแล้ว → กดปุ่ม "ดาวน์โหลดใบรับรอง"
   → ได้ไฟล์ PDF ใบรับรอง:
      - ชื่อนักศึกษา, รหัสนักศึกษา
      - รายการเครื่องมือวิจัย
      - วันที่อนุมัติ

 ⑥ ยืมเครื่องมือวิจัย
 ────────────────────────────────────────────────────────────────
   เข้าหน้า "ยืมเครื่องมือวิจัย":
   - เลือกเครื่องมือจากรายการ
   - กรอกชื่อผู้ขอยืม, วันที่, รายละเอียด
   - อัปโหลดใบอนุญาต PDF
   - กดปุ่ม OCR → ระบบอ่านใบอนุญาตแล้วกรอกข้อมูลอัตโนมัติ (ทางเลือก)
   → ยืนยันส่งคำขอ
   → คำขอมีสถานะ "รอตรวจสอบ"

 ⑦ ดูประวัติการยืม
 ────────────────────────────────────────────────────────────────
   ดูรายการคำขอยืมทั้งหมดพร้อมสถานะ:
   - รอตรวจสอบ / อนุมัติแล้ว / ปฏิเสธแล้ว
   - ลบคำขอได้ (เฉพาะที่ยัง "รอตรวจสอบ")
```

## เจ้าหน้าที่ (Admin)

```
 ┌─────────────────────────────────────────────────────────────────┐
 │                   ขั้นตอนการใช้งานสำหรับเจ้าหน้าที่                  │
 └─────────────────────────────────────────────────────────────────┘

 ① เข้าสู่ระบบ
 ────────────────────────────────────────────────────────────────
   เปิดเว็บไซต์ → กดปุ่ม "เข้าสู่ระบบ"
   → ล็อกอินด้วย CMU Account (Microsoft)
   → เข้าสู่หน้า Admin Dashboard อัตโนมัติ

 ② ดูภาพรวม (Dashboard)
 ────────────────────────────────────────────────────────────────
   ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
   │  นักศึกษา       │ │  เอกสาร       │ │  รอตรวจสอบ    │ │  อนุมัติแล้ว     │
   │  ทั้งหมด       │ │  ทั้งหมด      │ │              │ │              │
   └──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘

   + รายการกิจกรรมล่าสุด (Activity Feed)

 ③ จัดการเอกสาร
 ────────────────────────────────────────────────────────────────
   เข้าเมนู "จัดการเอกสาร":

   ┌─────────────────────────────────────────────────────────┐
   │  กรองตามสถานะ:  ทั้งหมด | รอตรวจสอบ | อนุมัติแล้ว | ปฏิเสธแล้ว  │
   │  สถิติ:  รอตรวจสอบ X ฉบับ | อนุมัติแล้ว X ฉบับ | ทั้งหมด X ฉบับ  │
   └─────────────────────────────────────────────────────────┘

   สำหรับเอกสารแต่ละฉบับ สามารถ:

   ┌─────────────┐   ┌─────────────┐   ┌─────────────┐   ┌─────────────┐
   │  อนุมัติ        │   │  ปฏิเสธ       │   │  ดู PDF      │   │  ลบ          │
   │             │   │  + เหตุผล    │   │             │   │             │
   └─────────────┘   └─────────────┘   └─────────────┘   └─────────────┘

   อนุมัติทั้งหมด:
   กดปุ่ม "อนุมัติทั้งหมด" → อนุมัติเอกสารทั้งหมดของนักศึกษาคนนั้น
   (กระทบเฉพาะเอกสารที่ "รอตรวจสอบ" เท่านั้น)

 ④ ดูรายชื่อนักศึกษา
 ────────────────────────────────────────────────────────────────
   เข้าเมนู "รายชื่อนักศึกษา":

   แสดงรายชื่อนักศึกษาทั้งหมด:
   - ชื่อ-นามสกุล, รหัสนักศึกษา
   - สถานะ: กำลังศึกษา / ลาออก / พ้นสภาพ
   - จำนวนเอกสารที่อัปโหลด

   คลิกชื่อนักศึกษา → ดูรายละเอียด:
   - ข้อมูลส่วนตัว + ข้อมูลวิทยานิพนธ์
   - รายการเอกสารทั้งหมด + อนุมัติ/ปฏิเสธ/ลบ

 ⑤ จัดการการยืมเครื่องมือวิจัย
 ────────────────────────────────────────────────────────────────
   เข้าเมนู "จัดการการยืม":

   กรองตามสถานะ:  ทั้งหมด | รอตรวจสอบ | อนุมัติแล้ว | ปฏิเสธแล้ว

   สำหรับคำขอยืมแต่ละรายการ:
   - ดูรายละเอียด: เครื่องมือ, ชื่อผู้ขอ, วันที่, ใบอนุญาต
   - อนุมัติ / ปฏิเสธ (พร้อมเหตุผล) / ลบ

 ⑥ ดูประวัติการใช้งาน (Activity Log)
 ────────────────────────────────────────────────────────────────
   เข้าเมนู "ประวัติการใช้งาน":

   แสดงกิจกรรมทั้งหมดในระบบ:
   - เข้าสู่ระบบ
   - อัปโหลด / อนุมัติ / ปฏิเสธ / ลบ เอกสาร
   - ส่งคำขอยืม / อนุมัติ / ปฏิเสธ / ลบ คำขอยืม

   กรอง:  ประเภทกิจกรรม + ช่วงวันที่
```

## สรุปเปรียบเทียบ

```
 นักศึกษา (Student)                          เจ้าหน้าที่ (Admin)
 ──────────────────────                      ──────────────────────
 เข้าสู่ระบบ CMU Account                     เข้าสู่ระบบ CMU Account
     │                                           │
     ▼                                           ▼
 ดูข้อมูลส่วนตัว + วิทยานิพนธ์                   ดู Dashboard (สถิติ + กิจกรรมล่าสุด)
     │                                           │
     ▼                                           ▼
 อัปโหลดเอกสารเครื่องมือวิจัย                   จัดการเอกสาร
 (PDF + ชื่อเครื่องมือ)                           (อนุมัติ / ปฏิเสธ / ลบ)
     │                                           │
     ▼                                           ▼
 ติดตามสถานะเอกสาร                            ดูรายชื่อนักศึกษา
 (รอตรวจสอบ / อนุมัติ / ปฏิเสธ)                   (ข้อมูล + จำนวนเอกสาร)
     │                                           │
     ▼                                           ▼
 ดาวน์โหลดใบรับรอง (เมื่ออนุมัติ)                 จัดการการยืมเครื่องมือวิจัย
     │                                           (อนุมัติ / ปฏิเสธ / ลบ)
     ▼                                           │
 ยืมเครื่องมือวิจัย                               ▼
 (เลือก + อัปโหลดใบอนุญาต)                      ดูประวัติการใช้งาน
     │                                           (ค้นหา + กรองวันที่)
     ▼
 ดูประวัติการยืม
```
