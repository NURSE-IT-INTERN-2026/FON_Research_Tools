2. บทบาทผู้ใช้งาน

🎓 นักศึกษา (Student)

  • ล็อกอินด้วย CMU Account
  • ดูข้อมูลส่วนตัว + วิทยานิพนธ์ (จาก API อัตโนมัติ)
  • อัปโหลดเอกสารเครื่องมือวิจัย (PDF)
  • ดูสถานะเอกสาร (รอตรวจสอบ / อนุมัติ / ปฏิเสธ)
  • ลบเอกสาร (เฉพาะที่รอตรวจสอบ)
  • ดาวน์โหลดใบรับรอง PDF (เมื่ออนุมัติแล้ว)
  • ยืมเครื่องมือวิจัย + อัปโหลดใบอนุญาต
  • รับอีเมลแจ้งเตือนเมื่ออนุมัติ/ปฏิเสธ

📋 เจ้าหน้าที่ (Admin)

  • ล็อกอินด้วย CMU Account หรือ Username/Password
  • ดู Dashboard: สถิติ + กิจกรรมล่าสุด
  • จัดการเอกสาร: อนุมัติ / ปฏิเสธ / ลบ
  • อนุมัติทั้งหมด (Bulk Approve)
  • ดู/เปิดไฟล์ PDF ตรวจสอบ
  • รายชื่อนักศึกษา + จำนวนเอกสาร
  • ค้นหา (รหัส / ชื่อ / วิทยานิพนธ์)
  • บันทึกกิจกรรม (Activity Log)
  • จัดการคำขอยืมเครื่องมือ
  • Export ข้อมูล (Excel/CSV)

Upload Flow (นักศึกษา)

กรอกชื่อเครื่องมือ + เลือก PDF (รองรับหลายฉบับ)
ตรวจสอบ: PDF เท่านั้น, ≤ 10 MB, ต้องกรอกชื่อทุกฉบับ
ยืนยันผ่าน Confirmation Dialog
บันทึกไฟล์ + สร้าง Document (PENDING) + ActivityLog
ส่งอีเมลแจ้งเจ้าหน้าที่

Approve Flow (เจ้าหน้าที่)

กด "อนุมัติ" บนเอกสาร PENDING
ยืนยันผ่าน Confirmation Dialog
อัปเดต → APPROVED + สร้าง Instrument
ตรวจสอบ: PENDING หมดแล้ว?
ใช่ → ส่งอีเมลแจ้งนักศึกษา (1 ครั้ง)

กฎที่เปลี่ยนแปลงไม่ได้

APPROVED / REJECTED = สถานะสุดท้าย
เปลี่ยนสถานะต่อไม่ได้
นักศึกษาลบได้เฉพาะ PENDING ของตัวเอง
เจ้าหน้าที่ลบได้ทุกสถานะ
"อนุมัติทั้งหมด" กระทบเฉพาะ PENDING
APPROVED เดิมไม่ถูก approve ซ้ำ
อีเมลแจ้งนักศึกษา: ส่งเมื่อ PENDING หมดแล้ว
ปฏิเสธ = ส่งทันทีทุกครั้ง
